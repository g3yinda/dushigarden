# 设计与动效任务书

v0.10.7｜2026-10-03｜Apple浅色＋原创可爱猫咪。当前任务书描述已批准并实施的界面；历史GPT页面稿和36秒样片仅为设计参考。

## 交付与视觉边界

微信小游戏 Canvas 与本地浏览器体验端具有真实交互，GPT内置生图只制作原创插画，牌名、规则、数字、倒计时和按钮由独立文本组件绘制。位图不等于可编辑UI或动画，历史剪辑不等于完整对局录像。项目不再使用Canva，不复制官方游戏美术或苹果品牌素材，不打包未经许可的字体。

复用 [设计规范](../DESIGN.md) 中Apple基底、系统字体、单一蓝色交互、薄边框、柔和圆角与克制阴影。名字、作用和下一步操作优先，颜色之外仍需名称和说明。触控目标至少44px，主按钮48px起，关键文字不依赖插画中文字。

## 页面与交互合同

| 页面/状态 | 当前呈现与操作 |
|---|---|
| 首页 | 炸弹猫图片优先，昵称左对齐且垂直居中，创建/加入、玩法和底部设置；手机一屏，不上下滑动；有原局时保留返回入口 |
| 建房 | 一屏居中弹框，标题和关闭同行；四档否定时长、不开计时、循环否定、两个六人扩展开关；简短副标题，创建按钮下留白；建房不滚动，规则和对局记录等阅读弹层可滚动；对局选择一屏完成 |
| 等待房 | 六位房号、规则摘要、邀请、准备、房主开始、调试Bot；每行固定两位玩家，2–6席，Bot自动准备 |
| 牌桌 | 所有头像在暖色椭圆桌范围内，本人下方；牌堆、弃牌、行动者/剩余回合；去除顺时针、完整内爆猫及手牌教学长文字 |
| 手牌 | 默认重叠、左右滑动、选中展开抬起，可多选；展开/收起与取消选择使用同款浅蓝胶囊；打出/抽牌固定底部且避开安全区 |
| 目标/组合 | 点选后打出，在居中弹层选放大头像、加粗姓名和公开剩余手牌数，再确认；三张组合同框进入点名页，不纵向滚动；三张声明不按对手手牌过滤 |
| 否定 | 固定在打出/抽牌上方，平时常驻灰态、闲置文字为空；可响应浅蓝高亮，进度缩短和剩余秒数，不限时无伪计时；本次不出后本层锁定 |
| 索要/预知/调整未来 | 交牌提示只在手牌区域；预知/重排独立弹框、一屏完成；他人仅知道正在处理，不收到牌序 |
| 炸弹/内爆/插回 | 公共提示谁抽到炸弹；拆弹和秘密位置本人操作。内爆首抽翻面插回、再抽不可拆弹；不可否定 |
| 出局/结算/重连 | 存活/出局和胜者准确，房主再开，真实网络失败可恢复；过期局面静默刷新 |
| 退出确认 | 普通对局同步保持打开，主动取消/完成退出/房间失效才清除；关整房二次确认 |

## 牌面

基础13种：炸弹、拆弹、攻击×2、跳过、索要、洗牌、预知×3、否定，困困/饭团/宇航/侦探/摇滚五种普通猫。扩展6种：内爆猫、定向攻击×2、反转、抽牌底、调整未来×3、野猫。总19种与统一牌背；功能文案与 [规则表](02-规则与卡牌交互.md) 一致。

在原牌尺寸内扩大插画、名称和作用文字，减少无效留白。侧签底色：猫与野猫淡紫、拆弹淡绿、否定淡红、攻击/定向攻击淡橙黄、其余淡蓝。炸弹猫单独使用稍深红侧签、浅红整体底色、鲜红名称；不能靠颜色代替功能识别。姓名和目标同样优先可读，长名字保留清晰层级。

## 动效与状态时序

公开行动逐条展示 **5秒＝0.5秒入场＋4.2秒停留＋0.3秒淡出**。头像姓名加大，蓝色动作/牌名独立一行；目标行动展示双方头像和姓名。普通同步不清空队列；换房/换局清理，不因动画发送重复指令或延长服务器响应窗。

抽到炸弹显示公开抽弹者的头像/姓名和“抽到了炸弹猫！”；单次约0.9秒爆炸动画，提示牌面仍保留完整5秒。抽牌、拆弹、洗牌、预知与否定使用对应状态反馈，不播放快速全屏闪烁。减少动态关闭爆炸/位移动画，保留同等时长文字和静态结果；声音关闭后所有信息仍可见。

## 验收与历史素材

320×568、375×667、390×844、430×932检查首屏、建房、等待两列和固定操作；小游戏牌桌与手牌在同屏固定，长手牌仅横向滑动，交牌只提示手牌，其他私密选择使用独立弹框、全操作一屏完成，主按钮不被遮挡。实际证据见 [验收记录](08-第一版验收记录.md#v095-建房一屏与全量复核)。真人新手4/5识别、iOS/Android帧率、后台、音频与弱网仍需真实设备，不记为已通过。

`assets/design/v0.2`、`v0.3`、`v0.5`及review目录保存GPT原图、提示词和当时检查。v0.3样片720×1280、30fps、36秒，使用固定场景；旧3秒展示、旧否定布局、旧人数不是当前规范。实际生产插画使用图集裁切与组件分层，独立全套美术导出和更丰富音效仍属后续工作。

固定布局：牌桌、手牌、底部操作按窗口安全区划分，阶段/选牌/提示不改变手牌位置；中央牌堆与头像放大。详情在手牌标题旁，对局动态从设置进入。适用于Canvas小游戏。


## 小游戏对局选择（v0.10.2）

索要交牌只在手牌区域显示细蓝框及索要者短提示，底部交牌按钮负责确认，不挡桌面或手牌。其余对局选择居中独立弹框，320×412极短视口及320×568、390×844、430×932仍无需纵向滚动；必选阶段仅本人可见。预知完整牌名、调整未来三行、插回位置步进、目标头像姓名、同框点名六项分页和退出确认优先均按DESIGN.md执行。此项只适用于Canvas小游戏。


## 拆弹展示与牌桌提示（v0.10.4）

拆弹公开动效以紧凑横排居中在牌桌，突出插画、玩家头像/姓名与秘密放回状态；本人插回框缩小整体留白并居中内容组，一屏完成任意位置/牌顶/随机/牌底。位置仍仅本人可见；内爆猫首次插回不称拆弹。常规剩余牌数14px蓝色粗体，短屏16px数字在牌堆内，危险警示保留红色。索要短提示在手牌底部居中，留出横向和底部间距，不移动手牌和底栏。


## 新牌提示与牌桌头像（v0.10.5）

新牌提示采用桌面中央紧凑横排，显示获得者头像、姓名和牌名，仍只向本人展示。预知与调整未来的私密说明内嵌选择框，不另排提示动效；公开出牌展示不受影响。牌桌头像按可用宽高放大到紧凑36–42px/本人40–46px、常规48–64px，姓名11px/14–15px、本人14/16px。小屏姓名与牌数并列，本人头像居中在桌底，保留固定手牌与底部操作区域。


## 全屏爆炸（v0.10.6）

抽到炸弹猫触发一次2.8秒全画布暖色爆炸：冲击波、放射光、火焰花瓣、带拖尾碎片与星光、烟团，具体层数见DESIGN.md。抽弹身份/牌名提示仍展示5秒。选择弹框/提示卡区域以圆角遮罩避让，拆弹和退出选择不受覆盖；不引入新弹窗或重排固定分区。减弱动态关闭这些动态层；非炸弹事件不误触发。保持图集缓存、确定性种子和原有帧驱动；真实手机帧率另验。

### v0.10.7 游戏名称展示

统一中文名称为“炸毛猫咪”。首页插画标题改由独立文字覆盖旧标题，浅奶油底与原人数标签保持一致，按插画尺寸缩放；小游戏、浏览器及兼容页面同步。牌桌、导航、分享、危险牌牌名、抽弹/拆弹/放回和日志文字统一，工程BoomCat与历史图稿保留。
