# 第一版运行与部署

版本 v0.1.1，2026-09-30。AppID：`wx529cf19d338aebcf`。当前交付是本地可运行的微信原生小程序与独立后端，未发布。

## 本地体验

在项目根目录，使用 Node.js 24：

```sh
npm start
```

打开 <http://127.0.0.1:8787/>。填写昵称后创建房间，将六位房间号输入另一标签页；两个标签页各自拥有独立开发身份。所有人准备后由房主开始。需要至少两席。单人验证时可由房主点击“添加验证 Bot”，选择 1–4 只，再点“我准备好了”和“开始游戏”；Bot 自动准备。详见 [Bot 指南](09-本地Bot验证指南.md)。

微信开发者工具导入 `/Users/yinda/workspace/codex/boomcat`，使用配置中的 AppID；小程序根目录是 `miniprogram/`。后端运行后编译即可。已有工具中的本地项目已导入并完成模拟器联调。`miniprogram/config.js` 的 `127.0.0.1` 指向运行模拟器的电脑，不能作为跨手机联机地址。

默认数据保存到 `.data/state.json`，房间、会话和对局快照可随服务重启恢复；在线状态重新建立。退出进行中的对局保留托管席位，回大厅后可以返回原局。开发身份仅允许服务识别的本机回环请求，不能将本地模式经反向代理对外开放。

```sh
npm test
npm run check
```

前者验证规则、房间、HTTP 和客户端行为；后者检查 JavaScript 语法、配置、页面文件、双端控制器一致性和小程序资源体积。它们不代替微信真机验收。

## 公网后端准备

需要一套能持续运行 Node.js 24 的服务、持久化磁盘和 HTTPS 域名。当前是单进程内存状态加原子 JSON 快照，适合第一轮朋友试玩；不能直接启动多个 worker 或多个实例共享同一快照。容器重建必须保留数据卷。正式扩大规模前再迁移数据库与跨实例同步。

复制 `.env.example` 为本机私有 `.env`，设置以下变量：

| 配置 | 说明 |
|---|---|
| NODE_ENV | 正式环境必须为 production；启用真实微信登录并关闭开发身份 |
| WX_APP_ID | wx529cf19d338aebcf |
| WX_APP_SECRET | 在部署环境填写，只存后端密钥配置，不进入客户端、仓库或聊天 |
| HOST / PORT | 直接部署通常使用 127.0.0.1 / 8787，并由 HTTPS 反向代理转发 |
| DATA_FILE | 可写的持久化路径，例如 /data/boomcat/state.json |

`.env` 不由 `npm start` 自动加载，部署时可使用：

```sh
node --env-file=.env server/index.js
```

反向代理应支持至少 30 秒的读取等待，长轮询正常等待最长 20 秒；API 响应不缓存。健康检查是 `GET /api/health`，生产响应的 mode 应为 `wechat`。服务端将 `wx.login` 的 code 交给微信换取身份，客户端不能自己声明 openid。

也提供了 Dockerfile，未在本机实际构建。使用容器时 HOST 应设为 `0.0.0.0`；示例 `.env` 内的 HOST 会覆盖镜像默认值。容器数据目录 `/data` 必须挂载持久化卷并对 node 用户可写。不要把 `.env` 中的密钥写进 Dockerfile。

## 小程序上线配置与验收

后端和域名就绪后，修改 `miniprogram/config.js`：`apiBase` 为实际 HTTPS 服务地址，`localMode` 为 false。微信后台配置对应 request 合法域名，`project.config.json` 的 `setting.urlCheck` 改为 true；微信工具本地设置中的同名选项也恢复检查。不得把 AppSecret 放进小程序。

执行 `node tools/check.js --release` 检查发布配置。当前本地版故意不满足发布检查，不能将常规检查通过解读为可直接上传正式版。

再验证真实微信登录、好友分享进房、2–5 台手机对局、切后台恢复、网络中断、响应窗和音效。账号主体、发布载体/类目、所需材料及审核结果须在微信管理后台确认，本地编译无法证明已具备发布资格。浏览器体验端只用于本地验收，不提供独立的生产微信网页登录。

已接入 [g3yinda/dushigarden](https://github.com/g3yinda/dushigarden) 版本维护。`.gitignore` 已排除私人环境、对局数据、工具私有配置及输出截图；首版基线保留为 v0.1.0 标签，Bot 扩展为 v0.1.1。备份快照仅在后端受控保存，恢复时停止服务并使用单一实例，不能把玩家手牌快照作为公开附件。
