## 规则与产品

支持2–6人私密好友房、六位数字房号。2–5人基础版；六人默认基础56张加完整内爆猫20张，共76张、起始牌堆28张，包含内爆猫1、定向攻击3、反转4、抽牌底4、调整未来4、野猫4。每人1拆弹+7张安全牌。不开五张不同或快速变体。

建房可关闭内爆猫、反转，独立且仅六人生效；关内爆用第五张普通炸弹补足危险牌，关反转移除4张，总72张/牌堆24张。再开继承选项，已有对局按其冻结规则继续。

出牌不倒计时默认关闭，开启时所有在线选择阶段不限时；否定独立10/20/30秒/不限时，默认10。可循环否定默认开启，奇数取消、偶数恢复；关闭时首张否定直接取消。只等待持否定者，本次不出不可撤回，无人响应直接结算；换层可重选。不限时否定离线者10秒后不出；其他离线选择依原阶段托管，全体真人离线5分钟中止。

房主可仅自己离开或二次确认关闭整房；确认不会被普通对局同步关闭。旧指令冲突静默刷新，不弹局面变化提示，不自动重发。Bot仅使用本人视图、自动准备，正式微信模式禁用。

## 当前 UI

Apple浅色、原创可爱猫咪、细边框、圆角、系统字体，不使用Canva。首页与建房一屏显示；等待页两列；桌内头像、折叠滑动手牌、胶囊展开/取消、居中目标弹层。否定固定在底部打出/抽牌上方，只有可响应时高亮。公开行动5秒，抽弹姓名与单次爆炸提示。牌面扩大图文且尺寸保持，五类浅色侧签，炸弹深红侧签/浅红底/鲜红标题。
