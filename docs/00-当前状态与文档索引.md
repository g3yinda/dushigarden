## 规则与产品

支持2–6人私密好友房、六位数字房号。2–5人基础版；六人默认基础56张加完整内爆猫20张，共76张、起始牌堆28张，包含内爆猫1、定向攻击3、反转4、抽牌底4、调整未来4、野猫4。每人1拆弹+7张安全牌。不开五张不同或快速变体。

建房可关闭内爆猫、反转，独立且仅六人生效；关内爆用第五张普通炸弹补足危险牌，关反转移除4张，总72张/牌堆24张。再开继承选项，已有对局按其冻结规则继续。

出牌不倒计时默认关闭，开启时所有在线选择阶段不限时；否定独立10/20/30秒/不限时，默认10。可循环否定默认开启，奇数取消、偶数恢复；关闭时首张否定直接取消。只等待持否定者，本次不出不可撤回，无人响应直接结算；换层可重选。不限时否定离线者10秒后不出；其他离线选择依原阶段托管，全体真人离线5分钟中止。

房主可仅自己离开或二次确认关闭整房；确认不会被普通对局同步关闭。旧指令冲突静默刷新，不弹局面变化提示，不自动重发。Bot仅使用本人视图、自动准备，正式微信模式禁用。

## 当前 UI

首页头像提供六猫四狗（编号0–9），另可主动点击原生微信头像按钮授权。头像本地保存，建房/加入时同步资料，等待页、牌桌、选人和行动角色共用同一来源；取消授权保留动物选项，不改游戏昵称。选择窗五列两行，一屏操作。真实手机授权和远程图片下载待验证；浏览器仅提供动物选择。见 [头像实施验收](implementation/player-avatars.md)。

游戏中文展示名称统一为“炸毛猫咪”：首页插画标题、牌桌、危险牌牌名、抽牌/拆弹/插回、导航、分享与公共/私密日志。旧房间日志在客户端显示时转换，不修改事件内容；工程名称与协议仍为BoomCat。官方来源和历史图稿保留原名。

v0.10.8 采用用户批准的温暖猫咪房间背景、奶油椭圆桌和较大头像/牌堆；折叠手牌露出横排小牌名、插画与分类色猫爪，单张选中或全部展开恢复完整作用说明。背景由GPT内置生图制作并缓存，加载失败回退奶油色；所有交互仍由Canvas代码绘制。分类底色、否定/计时/私密阶段与服务器规则保持原基线。详见 [温暖牌桌实施与验收](implementation/cozy-table.md)。v0.10.9在此基础上加入粗蓝色行动头像圈、原创猫咪牌背和牌堆数量间距，见 [行动圈与牌背实施记录](implementation/card-back-highlight.md)。v0.10.10修复折叠手牌末张的空白和滑动边界，见 [手牌末端修复与验证](implementation/hand-scroll-end.md)。v0.10.11按用户选择换用暖阳奶油色猫咪牌背，见 [暖阳版实施记录](implementation/sunshine-card-back.md)。v0.10.12按用户最新选择改用柔和粉红牌背，见 [粉红牌背实施记录](implementation/pink-card-back.md)。v0.10.13将本人头像和两行文字按实际显示宽度整体居中，见 [本版实施记录](implementation/self-seat-center.md)。

小游戏对战牌桌、手牌和底部操作分区固定，整页不纵向滚动；选择与阶段切换不移动手牌。交牌提示只在手牌区域居中并留边距，不卡住牌桌；其他对局选择使用独立弹框，一屏操作、不纵向滚动，点名分页与位置步进都在同框完成。手牌横向滑动；单张详情在标题旁，对局动态从设置进入。头像与中央牌堆放大，减少桌内空白。Apple浅色、原创可爱猫咪、细边框、圆角、系统字体，不使用Canva。首页与建房一屏显示；等待页两列；桌内头像、折叠滑动手牌、胶囊展开/取消、居中目标弹层；选人头像与姓名放大、内间距收紧，并实时显示公开剩余手牌数。否定固定在底部打出/抽牌上方，只有可响应时高亮。公开行动5秒，抽弹显示姓名和2.8秒全屏暖色爆炸，冲击波/放射光/火花碎片/烟团依次消散，保护拆弹弹框；减弱动态保留静态提示。拆弹后紧凑展示操作者与正在秘密放回，插回弹框内容居中；新牌居中展示本人姓名及牌名，预知私密说明仅在选择框内。头像/姓名随牌桌空间放大，小屏其他玩家姓名与牌数同一行；剩余牌数用加粗蓝字，短屏数字收在牌堆内。完整牌面保留用途文字，折叠牌采用图文猫爪露出区和五类浅色分类，炸弹深红侧签/浅红底/鲜红标题。
