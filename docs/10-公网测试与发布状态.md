## 现在如何用手机验证

首屏已精简，“是否选择否定”与“打出 / 抽牌”共同固定底部，否定在上、行动在下，不随页面滚动。否定面板大小/圆角/计时保持，长手牌和私密操作可滚到容器上方；出牌仍展示5秒。

此前否定只等待持牌者，无人可响应直接流转；同一窗口内其他人的不出不再拦截你的首次点击。没有否定时两按钮灰态且不计时，闲置文字为空；按钮居中并优先系统圆体。前后端需同时更新，重新编译扫码。此前头像稳定、等待房间两列及静默刷新保持。

1. 在当前微信开发工具中重新编译本项目，点击“真机调试”生成新的二维码；选择 iOS，并取消“局域网模式”。上版已配置这两项；二维码有时效，需重新生成获取本版。
2. 用手机微信扫码进入。关闭 Wi-Fi、使用 4G/5G，可验证公网连接。
3. 创建房间，添加最多五只 Bot，点击准备和开始；或让其他调试成员扫码后输入同一房间号。
4. 在建房“六人扩展规则”中分别设置内爆猫和反转，默认均开启；六人准备页显示完整或自选扩展及禁用项，牌桌仍精简。添加五只Bot后开局验证：关闭项不发牌、无对应动作；关闭内爆仍可用5张普通炸弹完成六人局。遇到错误时提供页面提示，勿发送调试访问码。

此版本使用测试身份与独立访问码，不是正式微信用户登录。调试包只用于受控测试，不公开分发。真机调试二维码的设备授权与连接方式仍由微信开发工具管理；公网后端解决的是游戏 API 跨网络访问。

`npm start` 或 `npm run dev:phone` 会生成对应本地配置。要恢复已配置的公网版本，在项目目录执行：

```sh
node --env-file=.env.preview tools/configure-preview.js
```

随后重新编译扫码。私人 `.env.preview`、`miniprogram/config.js` 与对局快照不上传 GitHub；本机旧配置备份在 `.data/client-before-public-preview.js`。

## 腾讯云运行结构

源代码：`/home/ubuntu/boomcat/releases/v0.8.1/`。镜像 `boomcat-preview:0.8.1`，后端容器 `boomcat-preview`，持久化数据卷 `boomcat-preview-data`。服务端口只绑定 `127.0.0.1:8790`，HTTPS 由 `boomcat-preview-tunnel` 转发。两个容器配置自动重启，未修改已有 SSH、Nginx 或防火墙规则。

服务端随机访问码保存在 `preview.env`，权限 600。代理回环请求仍需要有效访问码；无访问码的登录返回 403。客户端和后端均阻止把此配置当作正式版。容器重建应保留数据卷，并使用已有访问码，避免使现有调试包失效。

服务器健康检查：

```sh
ssh tencent-prod 'curl --fail --silent http://127.0.0.1:8790/api/health'
ssh tencent-prod 'sudo docker ps --filter label=app=boomcat-preview'
```

使用 Cloudflare 官方 Quick Tunnel 临时地址，无需新域名；不承诺正式服务可用性。隧道重建可能生成新地址，需要更新本地私人配置再编译扫码。不要用此临时地址替代已备案正式 HTTPS 域名。
