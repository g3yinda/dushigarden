| N08 | 房主断线或离开 | 对局持续，不获得强制看牌/踢人权力 |
| N09 | 全员断线超过 5 分钟 | 中止，不生成虚假胜者 |
| N10 | 服务重启时存在待结算行动 | 恢复到同一阶段，过期动作只执行一次 |

| N12 | 检查所有客户端与消息日志 | 看不到对手手牌、牌堆顺序、炸弹位置 |
| N13 | 无人有否定 vs 有人有否定 | 公开等待模式一致，不能据此判断牌况 |
| N14 | 对手观察插回动画与事件字段 | 无法获得真实插回位置 |
| N15 | 爆炸玩家的手牌封存 | 公共客户端不接收封存牌内容 |
| N16 | 索要/偷牌第三方客户端 | 只收到人数与张数变化，不收到转移牌面 |
| N17 | 再来一局 | 全新牌库、序号、首位玩家，所有人重新准备 |
| N18 | 加入满员/已开始/过期房间 | 有明确可恢复提示，不错误占座 |

## 设计与真机

| ID | 检查 | 通过标准 |
|---|---|---|
| U01 | 13 种牌面和牌背 | 数量齐全，五种普通猫可区分，无错误文案 |
| U02 | 不熟悉规则者看牌 | 至少 4/5 人在放大后 5 秒内说出主效果 |
| U03 | 对比索要、对子、三张 | 分别理解对方选、随机、点名 |
| U04 | 欠 1 次攻击回合 | 不误读成普通回合或“还要抽两张” |
| U05 | 小屏、长昵称、15 张牌 | 关键文字不截断，手牌可滚动，主按钮可点 |
| U06 | 快速点牌/切屏/减少动态 | 不误出牌、不丢响应窗口、结果一致 |
| U07 | 视觉 Demo | 效果图、牌面文案清晰；位图/分镜明确标注；真实动画单独验收，不宣称位图可编辑或可播放 |
| U08 | 声音关闭/减少动态 | 所有信息仍能读懂，无仅靠音效传达的结果 |
| U09 | iOS/Android、正常/弱网 | 记录操作延迟、恢复时间、动画表现；未测设备不写通过 |

发布门槛：规则与隐私案例全部通过，阻断及严重问题清零，至少 20 局涵盖 2/3/4/5/6 人且每种人数不少于 3 局。逻辑测试、效果图视觉检查、微信真机和多人联机验收分别记录，不互相替代。

## v0.5.0 完整内爆扩展验收

- 六人总76张，扩展分布1/3/4/4/4/4、4炸弹＋1内爆；2–5无扩展牌。
- 内爆首次翻面不消耗拆弹；再次抽到直接出局，末两人立即结算；明置顶/底公开、埋置位置私密。
- 定向攻击含自己/空手目标及攻击余债＋2；反转只减1债务、逆向普通攻击、二人生存跳过、否定不改变方向。
- 抽牌底普通牌、炸弹、首抽/再抽内爆，卡牌被否定不抽牌。
- 私密调整未来完整排列校验、不泄露、超时原序、不限时在线等待及离线托管、同步保留本地排序。
- 野猫搭普通猫/全野猫对子三张合法，混功能牌/两种普通猫/单张非法；三张点名危险牌拒绝。
- 旧六人快照继续旧规则，新局/再开采用新配置，Bot完成新增选择阶段，六人完整模拟最终结算。
