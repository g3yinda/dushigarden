## 5. API与运行资料的最小交接

此表据server/index.js整理，便于恢复工作，不是完整OpenAPI定义。

| 接口 | 用途/约束 |
|---|---|
| GET /api/health、/api/cards | 健康/模式及牌型目录；健康不证明AppSecret有效或存储已持久 |
| POST /api/session | 微信端提交新鲜code及资料，服务端交换身份，返回会话；生产网页无wx.login code不能直接建房 |
| POST /api/profile | 会话更新昵称/头像；正在对局限制资料修改 |
| POST /api/rooms、/api/rooms/join | 创建（房规字段）/输入code加入；鉴权、成员与人数由服务端验证 |
| GET /api/rooms/current | 恢复当前房间 |
| GET /api/rooms/:code?after=revision | 获取本人投影，版本不变长轮询；客户端正常25秒超时、服务端轮询20秒 |
| POST /api/rooms/:code/command | 准备/开局/退出/关房/再开及游戏动作；commandId去重，revision校验；对局动作校验gameId，否定另需当前窗口/层凭据 |
| POST /api/rooms/:code/bots | 仅local/preview可用，正式wechat返回403 |

请求JSON不超过8192字节；需鉴权的请求带Authorization: Bearer；业务错误含error/message，STALE使用409，房间关闭410、未授权401、权限403、限流429、登录上游暂不可用503。错误不自动重发已提交游戏动作。精确字段及去重返回语义以rooms.command与测试为准：当前重复相同命令返回最新玩家视图，不是固定缓存的原响应。

运行配置原始文本：HOST=0.0.0.0、PORT=8787、NODE_ENV=production、BOOMCAT_MODE=wechat、WX_APP_ID=wxf7af6d01a9bbfdbd、NODE_EXTRA_CA_CERTS=/app/cert/certificate.crt；AppSecret只在云端私下配置。填写值不带Markdown符号。重部署后核对健康版本/流量，再手机关闭开发调试测试；后台值没有本轮独立查询证据。
