# v0.9.0 循环否定、响应时长及退出确认

> 历史材料：本文件保留当时的设计、计划或验收，不作为当前行为说明。当前规则、UI、交付和待办见 [v0.9.5 当前状态](../00-当前状态与文档索引.md)。

用户于2026-10-02要求直接实现；既有Apple浅色及固定否定栏布局已确认。

1. 先复现响应阶段/当前玩家变化导致退出弹窗被清空，分离退出确认与出牌选择上下文。保留leave/close-room，房间关闭、换房、失去房主权限等仍按权限关闭。
2. 房间allowNopeChain为布尔值，默认true保留原引擎行为；false时首张否定立即取消动作。true时每层独立选择，奇数取消、偶数恢复，原动作只在最后结算一次，已出卡牌不退回。新层重置资格与截止；已放弃不能在本层改出，旧层请求仍拒绝。
3. 新房nopeSeconds只能为10/20/30/0，0代表不限时，默认10；恢复及再开旧房保留5/15等历史值。开局与再开继承全部选项。
4. 不限时否定deadline=null，客户端仍可响应并显示不限时；无否定玩家自动完成。在线持牌者全部完成才结算，断线座位单独宽限10秒后托管不出，不能让在线玩家提前结算。出牌不限时和否定不限时互相独立。
5. 固定否定栏本人可响应时浅蓝背景/蓝边框高亮，其他状态灰；不改结构与尺寸。10/20/30秒每层计时，最后3秒既有暖红提示保留。
6. 回归：奇偶1–4层、开关关闭、旧窗口、无限等待/全员确认、离线隔离、快照兼容、HTTP配置、Bot确认、两端弹窗更新与建房提交。实际窄屏UI、微信编译及公网验收另记。
