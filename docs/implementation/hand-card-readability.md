# 手牌辨识与分类色（2026-10-03）

用户指定保持既有卡牌大小，增大文字与猫咪图片、减少留白，左侧半小块按牌型着色。沿用 Apple 浅色圆角与系统中文字体。普通猫及野猫淡紫#efe7fa、拆弹淡绿#e6f3e2、否定淡红#fce5e8、攻击及定向攻击淡橙黄#fff0d8、其他淡蓝#e6f1fc。选中蓝边、勾选与上移保留，分类底色不被选中状态替换。

实施：共享控制器提供手牌分类及独立插画裁切元数据。只在手牌模板中使用纯插画裁切，排除原图中的重复小字；裁切视口居中等比覆盖，不改图像文件或其它场景的裁切。手牌主体尺寸、重叠间距、行宽公式保持。牌名约13px、作用约11px，图片约73px高；定向攻击及调整未来等长牌名适度压缩图片高度，保留完整文字。折叠侧签约14px，具备明确分类色。

验收：分类映射测试、现有回归、打包及官方微信编译；隔离页面320/390/430宽度，折叠/展开、单选/多选/取消，核对尺寸不变、分类色不因选中丢失、长牌名和作用不溢出、不出现图片中的重复小字。用户原真机对局不关闭；微信模拟器检查可见手牌，真实手机扫码复核。
