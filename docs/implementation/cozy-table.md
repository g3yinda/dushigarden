# v0.10.8 温暖牌桌与图文折叠手牌

2026-10-03，用户批准本轮 GPT 场景图并要求直接改代码。适用于当前微信小游戏 Canvas 对战页，旧浏览器/WXML保留各自基线，未改规则或后端。

## 实现

- `miniprogram/lib/cozy-table-ui.js` 负责房间配景、响应式奶油椭圆桌、围坐头像标签、牌堆和折叠牌绘制，`canvas-ui.js` 保留触控、业务状态、底栏和弹框。
- 独立房间背景采用 GPT 内置 image_gen，原图/提示词在 `assets/design/v0.10.8/`，运行 JPG 约35KB、最长边960px。按屏幕居中等比裁切、缓存加载，失败使用奶油底色。牌桌、姓名/牌数、牌名、猫爪和按钮为真正 Canvas 组件。
- 2–6人继续按本人视角围坐。正常头像48–72px，本人略大；矮屏按空间收缩，标签合并姓名/牌数。五人短屏上下座位避让；牌堆不覆盖座位，危险警示只在牌堆旁，不重复压住本人头像。
- 手牌区域固定，正常192–220px、矮屏106–154px，阶段/选中/展开不改变其位置。折叠每张露出44px的横排小牌名、独立插画和分类色猫爪；牌体64/70px宽，支持横滑。选中及展开按96/112px宽显示原完整牌面，蓝边/勾选、详情、取消选择、多选与出牌确认保留。取消/展开仍同款胶囊。
- 猫/野猫淡紫、拆弹淡绿、否定淡红、攻击/定向攻击淡橙黄、其他淡蓝；炸弹深红标识、浅红底、鲜红名称。原图集不替换。
- 否定56px、出/抽48px及其资格/计时/反否定、退出确认、交牌手牌内提示、独立选择弹框和爆炸队列继续复用。
