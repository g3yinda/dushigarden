## 设计

进入每层否定窗口时，只有存活且自己手牌中有否定的玩家自动看到居中选择。展示原出牌者、原动作、当前生效/取消状态、打出后的结果，以及大号剩余秒数。提供“打出否定”（奇数层为“打出反否定”）和“本次不出”。关闭按钮同样只收起当前提示。“本次不出”不发送命令，不消耗牌、不缩短全桌窗口；保留桌面手动否定入口以便截止前改变决定。新一层重新询问，同层同步不重新弹出。

用房间号、对局编号、pending 原动作及 nopeCount、deadline 标识窗口，点击按钮携带该标识。点击前重新检查该标识、自己的存活/手牌和校准后的截止时间，拒绝旧窗口按钮。后端原 revision 校验继续裁决并发。请求失败且窗口尚未结束时保留提示以便重试；窗口到期、阶段变化、失去资格、离开或房间关闭时清理提示。

桌面响应提示统一为强调卡片：明确标题、原动作和奇偶状态，醒目大号秒数、渐减进度条。最后 3 秒切换暖红边框并文字提示“即将结束”；无闪烁，减少动态同样可读。没有否定的玩家也看同一公开倒计时，不能据此获知其他人的手牌。弹窗与牌桌共用服务端时钟，动画位于弹窗下层。
