# v0.11.0 六猫四狗与微信头像

2026-10-03用户授权增加头像选项。沿用当前Apple浅色，保留原四猫，加入雪团/栗子两猫与布丁/豆豆/棉花/可可四狗，共十个内置选项。

首页点击昵称左侧头像打开五列两行独立圆角窗，原生微信按钮在下方；316px内适配五种手机，触控不小于44px，不纵向滚动。用户点击并授权后仅使用avatarUrl，不覆盖游戏昵称、不强制授权。头像URL持久化与内置编号分离，动物选择清空URL；服务器、房间席位、开局、公开投影、选人和行动角色同步。浏览器和旧模板显示支持十个来源，浏览器不伪造微信接口。

客户端与服务端仅接受wx.qlogo.cn或thirdwx.qlogo.cn的合法头像路径；客户端把微信返回的HTTP升级为HTTPS，服务端拒绝非HTTPS、伪域名、凭据、端口、片段、本地文件和非头像路径。服务端不代抓取图片。渲染失败回退内置头像；现有头像图集和新图集启动时加载，地址缓存复用，不在点击时重新取图。

小游戏bridge使用wx.createUserInfoButton（withCredentials:false），按Canvas窗口几何创建；普通重绘不重建按钮，窗口关闭、后台与销毁立即移除，尺寸变化重定位，迟到回调不能覆盖已选择的动物。拒绝后保留窗口和动物选项。

GPT内置生图原图与完整提示词：assets/design/player-avatars。运行图集576×384，65,508字节；微信包源码约1.87MiB。未使用Canva或额外付费API。

验证：526项完整自动测试全部通过，包括2–6人规则/HTTP基线、头像编号/URL、安全校验、快照恢复、资料到牌局投影、授权按钮生命周期、缓存失败兜底。旧启动测试夹具补入新shared模块；旧图集数量测试更新为五个并保留不重取断言。npm run check通过。

生产Canvas渲染五尺寸头像窗口（320×412、320×568、360×640、390×844、430×932）、狗狗首页、混合动物等待房/牌桌/选人窗，9张场景及1张尺寸对照图保存在output/acceptance-v0.11.0；已目视检查尺寸对照与选人窗。均为独立数据真实绘制，不是手机实拍。微信开发工具观察到新wechat-avatar.js增量编译与Errors:0/Warnings:2；自动化点击没有确认打开头像窗，不将此计为原生授权验收。
