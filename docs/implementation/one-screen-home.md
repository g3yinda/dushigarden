# 首页一屏布局（2026-10-02）

用户要求直接修改首页：删除BOOMCAT眉题、朋友局大标题与副标题，炸弹猫插画放首位；设置移到下方；不同手机均显示完整首页，不允许上下滚动。沿用已批准Apple浅色、圆角与猫咪素材。

实施：原生与浏览器的首页独立flex容器占满可用窗口，底部保留安全区，操作区域不收缩，插画保持比例按余下空间缩放；有返回对局按钮时进一步收紧插画。底部并列玩法说明/设置，原生阻止首页触摸滚动，浏览器仅在大厅锁定页面滚动。房间/牌桌保持原滚动，弹层单独滚动。

验证：320×568、320×640、390×844、430×932以及微信原生可用窗口；检查顶部无文字、设置底部、所有按钮可见、拖动没有页面位移，建房/设置/规则弹层可用。检查含恢复入口布局；微信编译和现有回归通过后同步测试版及仓库。
