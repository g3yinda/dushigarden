# v0.4.0 六人局、公网测试与微信发布

> 历史材料：本文件保留当时的设计、计划或验收，不作为当前行为说明。当前规则、UI、交付和待办见 [v0.9.5 当前状态](../00-当前状态与文档索引.md)。

用户授权（2026-10-01）：玩家数扩展为 2–6 人，真机支持公网跨网络测试，并发布微信版本。沿用既有 Apple 浅色与原创猫咪；不使用 Canva。

## 实施范围

1. 扩展房间、规则、Bot 与围坐布局到六席；单人可添加五只验证 Bot。2–5 人牌库不变；六人仍发每人 8 张，六张拆弹各一张，增加第五张炸弹（本项目朋友局扩展），起始牌堆 9 张。规则版本区分六人扩展。
2. 测试六人开局、牌数守恒、完整对局、五 Bot、房间第七人拒绝、私密投影、围坐和已有否定响应。保持旧房间快照兼容。
3. 核对可用云资源、HTTPS 域名和微信后台发布资格。现有后端需要单实例 Node.js 24、持久化磁盘，不能用无状态静态托管冒充正式游戏服务器。跨网络测试及正式版本使用实际后端地址，不再依赖 Mac 同 Wi-Fi。
4. 在用户已有资源/确认费用范围内部署；AppSecret 只在受控后端环境配置。设置 request 合法域名、客户端生产登录与域名校验；验证公网健康、微信登录及多人对局。上传代码、配置体验版、提交审核，并在审核通过后执行发布。需要管理员扫码等本人认证时交接，不代填不存在的备案、资质、隐私或版权材料。
5. 分别记录实现、自动测试、模拟器、真实公网访问、真实微信登录、体验版、审核提交和正式发布状态，不互相替代。若外部资源缺失，完成独立代码与部署准备，并明确待用户提供的具体条件。
