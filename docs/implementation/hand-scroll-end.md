# v0.10.10 折叠手牌尾部空白修复

2026-10-03，用户截图显示横滑到最后一张折叠牌后仍有多余空白。

原因：折叠每张实际展示44px的牌名、图片和猫爪，但末张按64/70px牌体计入总宽度，末端留下20/26px没有内容的区域。

修复：`miniprogram/lib/canvas-ui.js` 将最后一张折叠牌的绘制宽度、点击宽度与滑动总宽度统一为44px。末张选中或手牌展开时仍按完整牌面计算；不足一屏时不能横滑，移除卡牌后自动限制旧滑动位置。牌桌、颜色、底栏和规则不变。

验证：

- 两个新增回归在修复前均失败，修复后Canvas67项通过；覆盖320×568、390×844、430×932及1/4/8/35张手牌，拖到尽头再拖不能越界，也不会误选牌。
- 选中末张、多选、展开、收起及移除末张后均检查滑动终点。
- 全量 `npm test` 511项通过、0失败；`npm run check`通过，源码资源约1.80MiB；`git diff --check`通过。
- 生产Canvas独立渲染三尺寸的折叠末端、末张选中和展开，共9张，保存在 `output/acceptance-v0.10.10/`。使用独立数据及本机字体，非微信真机截图。
