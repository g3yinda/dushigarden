# v0.10.9 行动头像、可爱牌背与数量间距

2026-10-03，按用户要求在已批准的温暖猫咪牌桌上维护，适用于微信小游戏Canvas。旧浏览器/WXML维持原呈现，规则和后端协议不变。

## 修改

- 行动头像由2px细圈变为5px蓝色圈，叠加9px浅蓝衬圈；极小头像按比例缩减。圆圈画在头像范围以内，本人和其他玩家都随回合切换，结束后去除。没有额外闪烁动画。
- GPT内置image_gen制作浅蓝小猫抱猫爪的原创牌背，原图与完整提示词在 `assets/design/v0.10.9/`。运行图 `miniprogram/assets/card-back-v1.jpg` 最长边384px、约29KB，等比裁切，不拉伸；缓存复用，加载失败绘制猫爪兜底，数字和操作继续可用。
- 正常牌堆底与剩余数量文字约8.5px，紧凑模式约4px。紧凑桌区阈值320px，危险警示需要时为数量腾出空间；正常牌堆按本人头像上界限制高度，避免布局临界处遮挡。极短桌区继续用数量小标签兜底，手牌与底栏不移动。

## 验证

- 三个新增测试先运行均失败，接入后Canvas65项通过：图片绘制/缓存/失败回退、数字与牌堆/危险警示/本人头像间距、他人行动粗圈及结束去除。
- 间距覆盖320×568、360×640、375×667、390×844、430×932，以及390宽688/708/728/748高的布局临界情况。另用独立临时脚本检查390宽、568–938高每10px的数量间距，全部通过。
- `npm test`：509项通过、0失败；包含2–5人基础、6人扩展、Bot、真实HTTP回归。`npm run check`通过，源码资源约1.80MiB，`git diff --check`通过。源码体积不等于微信实际上传压缩包。
- 生产Canvas代码用独立数据及本机字体渲染58张场景及五屏对照，保存在 `output/acceptance-v0.10.9/`。已查看五屏对照、390×844他人行动及320×568公开危险提示，非微信真机截图。

本轮未上传微信或正式发布，未部署后端。真实手机扫码、帧率、图像内存和安全区仍需真机验收；之前开发工具编译记录不作为本轮真机证据。
