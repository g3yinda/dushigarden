# 炸弹猫醒目提示（v0.9.4）

沿用用户已批准的 Apple 浅色可爱风格，卡牌尺寸与手牌折叠方式保持。炸弹猫侧签淡深红 #f1b4b9，牌底浅红 #fff1f2，牌名鲜红 #d9182b；选中仍使用蓝边与勾选。其它牌型配色保持。

抽到普通炸弹猫时记录结构化公开事件（仅抽牌者与已公开炸弹），所有玩家的动画队列都显示头像、大号姓名、红字“抽到了炸弹猫！”及炸弹牌。即使直接出局，或者轮询合并了拆弹/插回阶段，仍能展示一次；不泄漏未公开手牌。旧服务快照进入拆弹时保留带玩家身份的兼容提示。

每次抽弹展示 5 秒，开头 0.9 秒播放一次暖色扩散光圈与六颗碎片，随后稳定停留。不闪屏、不震动布局、不遮挡底部操作，减弱动态及系统减少动画时隐藏爆炸效果。首次抽到未翻面内爆猫继续使用已有提示。

验证计划：公开事件及合并快照测试；双端控制器一致、完整测试和微信编译；不同手机宽度的实际渲染及减少动画检查；更新公网测试环境与真机调试包。
