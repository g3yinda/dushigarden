# 2026-10-04 微信审核建房网络失败

最新进展：用户已确认云托管部署成功；当前本地客户端已切换callContainer，移除临时HTTP/测试身份，开启urlCheck。下方临时配置和六项阻塞是切换前诊断证据；新版体验包和关闭调试实测待完成，见[云托管验收](cloudrun-transport.md)。

## 结论和证据

用户提供的审核截图显示，小米11和iPhone11均在创建房间时出现“网络连接失败，请检查服务是否启动”。平台通知本次审核未通过，原因是手机端无法继续正常游戏流程。游戏资源能够打开，但建房依赖的后端请求失败。

此前用户确认当前AppID的request合法域名未配置，并实测体验版打开调试后能够创建房间。这确认了域名校验阻塞。微信官方[小游戏示例说明](https://github.com/wechat-miniprogram/minigame-demo#注意)也明确要求配置合法域名，调试模式仅用于调试。

本轮重新验证的实际状态：

- 腾讯云容器`boomcat-preview`运行镜像`boomcat-preview:0.11.2`，本地和临时公网HTTPS健康接口均返回`ok:true`，模式为`preview`。
- 从本机使用现有私有测试配置访问公网`/api/session`返回HTTP 200，成功创建独立诊断身份，未创建房间；未输出访问码或会话令牌。
- 当前本机客户端指向临时`trycloudflare.com`地址，`publicPreview`、`phoneDebug`、`localMode`均为true，包含调试访问码；不记录或输出访问码。
- 项目`urlCheck=false`，所以本机开发工具正常运行不能证明微信审核环境正常联网。
- 服务器运行模式是`preview`，未配置生产微信登录AppSecret；上传代码的私钥不替代AppSecret。
- 未读取或解包用户上传的1.0.0成品，以上配置描述指当前本机源码；未改变微信后台版本、审核记录或体验版。

## 项目内完成的修复

1. 网络错误按域名拦截、TLS/证书、超时、主动取消及其他连接失败区分，错误对象带稳定分类码。缺少errMsg不会导致额外异常；不向提示或日志转发原始请求地址、访问码或凭据。HTTP业务错误仍使用服务器返回信息。
2. 新增`npm run check:release`入口，发布配置检查一次列出全部阻塞项，非零退出；拒绝调试身份/访问码、临时隧道/IP/本地/示例地址、不合规HTTPS地址和关闭域名检查。此检查不能自动查询微信后台域名白名单、备案或审核条件，也不能阻止用户直接点击工具的上传按钮。
3. 更新当前状态和部署说明，区分源码回归通过、正式网络就绪、上传、审核和发布。

这些修改提高诊断准确性并避免再次误判发布条件，不代表审核网络根因已修复。正式域名/云托管资源未确定前，保留现有测试服务和本地配置，避免中断已能运行的调试版本。

## 正式修复路径和验收

沿用已有腾讯云服务器时：

1. 确认用户自己的可用备案域名，配置API子域名解析、有效HTTPS证书和反向代理；不能将IP或当前临时隧道作为正式地址。
2. 在受控服务器环境配置新AppID和AppSecret，部署`wechat`模式的独立正式服务；保持现有测试数据和测试服务可回退。AppSecret只在服务器保存，不进入客户端或聊天。
3. 客户端`apiBase`指向正式HTTPS域名，`localMode=false`，移除`publicPreview`/`phoneDebug`/调试码；工具启用合法域名校验。
4. 由有权限人员在当前AppID微信后台配置同一request合法域名。配置文件检查通过不等于这一步完成。
5. 运行`npm run check:release`，在手机关闭开发调试后验证真实微信登录、创建/加入好友房、2–5人基础规则及6人扩展、对局同步和退出；检查Wi-Fi与蜂窝网络。
6. 上述验证通过后再上传新版本，设为体验版复验，最后重新提交审核。不能要求审核人员打开调试来绕过配置问题。

若用户选择已开通的微信云托管环境，须先核对当前小游戏账号的支持情况、环境和服务，再部署后端并适配客户端调用；仅创建或选择云环境不会迁移现有Docker服务或改变现有wx.request请求。

## 本轮验证

- 修改前，两项真实业务层网络回归失败：域名错误缺少分类码；空errMsg未正确拒绝。发布检查模块尚不存在。
- 修改后，网络、前端、小游戏运行桥及发布配置相关83项测试通过。
- 全量533项自动测试通过；首次沙箱运行因不允许监听回环HTTP端口而失败，获准使用本机测试端口后重跑通过。
- 语法、小游戏入口和资源检查通过，源码包约1.87MiB；`npm run check:release`以退出码1列出六项真实配置阻塞，直到外部资源和生产配置完成前应继续失败。
- 本轮没有重新上传微信、提交审核或修改线上服务；真实关闭调试手机验收待正式资源配置。
