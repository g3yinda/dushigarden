# 恢复折叠手牌

> 历史材料：本文件保留当时的设计、计划或验收，不作为当前行为说明。当前规则、UI、交付和待办见 [v0.9.5 当前状态](../00-当前状态与文档索引.md)。

用户要求恢复上一版认可的重叠手牌，并允许收起。沿用 Apple 浅色及原有卡牌美术；默认折叠，左右滑动选牌，选中牌抬起，保留多选和下方打出按钮。提供“展开手牌 / 收起手牌”切换，不改变选中状态和对局；普通同步保持展开状态，新对局恢复折叠。

根因：小程序 app.wxss 的 `button.card { margin: 0 !important }` 覆盖了页面的负间距，同时全局宽度和内边距也覆盖了手牌尺寸。浏览器版未受这条规则影响。用手牌范围内的高优先级样式修复，避免影响牌堆和详情卡。
