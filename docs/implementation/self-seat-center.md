# v0.10.13 本人头像与文字整体居中

2026-10-03，用户要求本人头像及右侧文字作为一个整体居中。

原因：正常桌区按头像中心定位，文字随后放在右侧；紧凑桌区虽有固定组合宽度，但实际文字与预留宽度不同，仍存在视觉偏移。

修复：`miniprogram/lib/cozy-table-ui.js` 按原字体和宽度限制先完成长文字省略，再测量实际显示的姓名和第二行文字宽度。本人水平组合宽度为头像＋原8px间距＋较宽的一行文字，以组合中心对齐牌桌中心；原头像大小、文字两行左对齐、颜色、高亮、底部高度及其他玩家布局保留。

验证：

- 新增真实绘制边界回归，修复前失败，修复后Canvas68项通过。覆盖320×568、360×640、390×688、390×844、430×932，各2–6人、短/长昵称、普通回合和否定阶段；同时验证组合中心及桌框边界。原座位/牌堆避让、固定手牌和滑动边界测试继续通过。
- `npm run check`、`git diff --check`通过，源码资源约1.80MiB。本轮只修改装饰布局，未重复完整规则/HTTP回归，511项是v0.10.10的历史验证。
- 生产Canvas渲染五尺寸正常牌桌、320/390宽危险提示和长昵称共9张及五屏对照，位于 `output/acceptance-v0.10.13/`。已查看390×844正常牌桌与320×568长昵称，使用独立数据及本机字体，非微信真机截图。
