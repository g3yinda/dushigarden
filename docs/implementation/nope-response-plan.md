# v0.3.2 否定响应确认与页面内操作

用户要求：本轮选择不出即结束本人响应，不能撤回；全员完成或超时即可结算；选择固定在原页面，不弹窗。沿用已批准 Apple 浅色与可爱猫咪。

1. 服务器保存每个存活玩家本轮 `waiting / passed / played` 状态。所有存活玩家均参与，可不出牌确认，不根据别人是否持牌自动确认，避免泄露手牌。拒绝同层重复选择及旧层命令；全员确认立即执行原效果或取消。
2. 每张否定开启新反否定层，出牌者该层为 played，其他人重新 waiting，保留反否定链。倒计时仍采用建房设置，未响应者到期自动结束。已确认玩家本人不再显示倒计时；其他人继续计时。旧快照无响应表时视为所有存活玩家 waiting。
3. Bot 选择不出时也提交服务器指令，不反复操作。两端复用状态派生，原有提示区固定于桌面下方、手牌上方；显示“是否选择否定”、操作和响应进度。确认后显示已完成及等待人数。删除自动弹窗与重复否定按钮。
4. 测试覆盖不可撤回、提前结算、反否定重开、截止、无牌与旁观、服务器重启恢复、幂等和两端失败重试。保留手牌折叠、动效和房主关房功能。
5. 独立浏览器对局验收与截图，微信开发工具编译；保护用户现有对局。更新需求/设计/验证记录，发布 v0.3.2 到既有 GitHub。

完成：服务器、Bot、两端固定提示、回归、独立双客户端验收和微信工具编译均已执行。iPhone 扫码验收待用户操作。
