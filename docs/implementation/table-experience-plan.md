# 共同牌桌与选牌体验实施计划

> 历史材料：本文件保留当时的设计、计划或验收，不作为当前行为说明。当前规则、UI、交付和待办见 [v0.9.5 当前状态](../00-当前状态与文档索引.md)。

2026-09-30。依据用户明确提出的五项修改直接实施，沿用已批准 Apple 浅色 + 可爱猫咪；没有更换设计风格。

**目标：** 让朋友围坐在同一张牌桌上，清楚看见出牌，以可滑动重叠手牌进行单张/组合选择；建房可选择不限时。

**架构：** 保留 Node.js 权威状态与双端原生组件；房间保存 `options.noTurnTimer` 并传入每局引擎。双端共享控制器提供相对座位、选牌、展示队列与时长。用户点打出才打开确认/目标弹窗，服务端收到最终确认后执行指令。无新增依赖或付费资产。

## 行为约定

- 出牌动效约 3 秒：约 0.5 秒进入、2.2 秒清晰停留、0.3 秒淡出。相邻效果排队展示，同步新状态不会清空或重启动画。出牌展示具体牌面与出牌者；组合显示牌种和张数。新房/新局/退出清理旧队列，不泄露别人抽到的牌。减少动态仍保留静态展示。
- 新建房先弹出设置，“出牌不倒计时”默认关闭；说明与准备页均显示房间模式。否定窗口仍保留 5 秒；用户已确认行动、索要交牌、预知、拆弹和插回全部不限时。在线玩家不限时阶段不自动操作；退出/断线仍保留原托管与全员离线中止，不能让无限等待阻止清理。再开沿用房间选项，旧快照默认计时模式。
- 共同牌桌：浅暖椭圆桌面，自己固定下方，其余玩家按相对顺序围坐；2–5 席不重叠，桌中央是牌堆、真实弃牌和回合状态。牌桌与手牌连续布局；当前玩家用蓝色细圈和文字提示，出局明确标记。
- 手牌：横向可滚动重叠卡组，每张至少露出约 44px 的带名称侧栏，卡序不变；选中抬起并突出蓝框，支持取消、多选与组合。选中牌的完整名称/用途在下方预览，常驻打出按钮按合法性启用，详情与抽牌按钮可用。滚动位置在选牌、同步和弹窗后保留，不因整页渲染跳回第一张。
- 目标选择：打出后居中弹窗，明确显示所选牌；候选玩家头像、姓名、牌数和选中状态。需要声明牌名的三张组合在同一弹窗完成。点击头像只选目标，最终“确认打出”才提交；取消不丢手牌。局面变化关闭过期确认，仍使用 revision 校验。
