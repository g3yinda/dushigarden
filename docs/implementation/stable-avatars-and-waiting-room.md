# v0.7.1 头像与等待房间维护

2026-10-01。沿用已批准的 Apple 浅色和可爱猫咪样式。

## 问题与改动

1. 原生选牌会重新发送整个派生视图，包括未变化的玩家头像；改为逐字段比较，使用微信数据路径提交变化。数组成员或顺序变化时替换数组，公开行动的 renderId 变化必须保留新动画节点。
2. 浏览器操作会重新构建整个页面；改为局部 DOM 更新，按玩家 ID 保留头像节点和相同图片属性。按钮区分卡牌 ID 与否定秒数，保留事件委托、表单值和选中状态。
3. 等待席位固定为两列等宽网格，列宽允许收缩，长昵称换行，避免不同屏幕宽度挤出第三列或横向溢出。
4. 出牌状态冲突时静默获取最新局面，移除“局面已变化”提示；不重放旧操作。连接或其他操作错误仍正常显示。

## 验证与交付

- 原生选择/取消选择不发送玩家与头像字段；身份、成员和顺序变化仍可更新。
- 浏览器头像节点与未变化的图片属性保留，玩家增删、三档否定按钮和弹层正常更新。
- 保留连续出牌的独立动画节点及 5 秒展示；全量回归检查。
- 等待房间检查 320、390、430 像素宽度及微信 iPhone 模拟器六席布局；原生选牌、取消、展开和收起验证。
- 更新既有腾讯云预览，保留访问码、数据卷、隧道、备份和回滚容器；生成新 iOS 调试包。此次不包含微信正式上架。
