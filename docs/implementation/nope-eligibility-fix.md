# v0.7.2 否定资格与单次响应修复

2026-10-01，按用户四项测试反馈维护，沿用已批准的 Apple 浅色与可爱猫咪。

1. 服务端按当前实际手牌决定资格；没有否定的存活玩家自动完成。无人能响应立即结算，否则持牌者全选完或超时结算。新层重新计算，已出的否定不能再响应本层。旧快照无牌等待项在投影/命令/定时处理中兼容。
2. 修复多人响应竞争：他人不出会变更房间版本，原客户端首次点击因此收到409。只对精确匹配当前动作/层/截止的响应容忍版本变化，不重试过期操作，不弱化普通命令版本检查。动作事件ID避免同毫秒同牌种后续动作错误复用旧凭据。幂等命令、成员、手牌与截止检查保留。
3. 双端没有否定时保持灰态、个人进度归零，闲置计时文字留空。两个按钮双轴居中，优先系统圆体，缺失时回退中文字体。
4. 先复现失败回归再修改；旧检查按新房规调整，保留截止、链奇偶、守恒、Bot和扩展流程。完成全量及真实界面验收后更新既有公网预览、GitHub与新iOS调试包。
