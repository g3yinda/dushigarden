# 建房一屏与全量复核（v0.9.5）

## 用户要求与实施边界

沿用已确认 Apple 浅色风格。建房弹框所有控制和创建按钮在手机可用窗口内可见，无上下滚动；不删除规则配置、不减小触控目标、不影响其他弹层的滚动。用同一行标题/简短说明承载不倒计时、循环否定和两个扩展开关，删除重复介绍，关闭内爆的说明放入该开关副标题，避免额外增高。

## 工作计划

1. 复现并测量现有建房滚动；双端采用独立 create-sheet 样式，关闭建房纵向滚动，保留四档否定和全部开关。
2. 320×568、375×667、390×844、430×932及原生模拟器验收；全部配置组合、创建按钮、关闭按钮可见。检查首页、两列等待页、默认折叠/展开/多选、目标弹层、固定否定和动作栏、危险提示及减少动画。
3. 完整运行现有测试，执行2/3/4/5基础与6完整扩展到胜者，并对四组可选扩展、否定开关/时长、不限时、离线托管、隐私投影与恢复做补充矩阵。真实接口验证建房、加入、准备、开局、合法动作、重连、结束及关闭。
4. 复核全部项目Markdown：当前需求/规则/运行说明与代码保持一致；历史设计、计划和旧验收保留当时事实并标注历史，统一指向当前状态，不将未测试的真机/审核写成完成。
5. 记录失败与修复、实际覆盖及待验证项；官方微信编译、包体检查和隐私检查后更新公网测试版本与GitHub。
