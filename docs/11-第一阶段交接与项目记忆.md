## 2. 已完成的产品与规则

### 房间系统

- 2–6人私密好友房、六位数字房号、创建/输入房号加入、准备、房主开局、结算和再来一局。
- 同一玩家不能同时占多个房间；房主可仅自己离开，或二次确认关闭整房；关房不产生胜者。
- 房主转移、退出对局托管、返回原房、前后台恢复、在线心跳、长轮询同步、离线维护及过期房间清理。
- 开局由服务端裁决；命令去重、状态版本及否定窗口凭据防止重复扣牌和过期动作重放。
- 验证Bot支持1–5只，使用普通指令和本人玩家视图，不偷看对手/牌堆；仅local/preview开放，正式wechat模式禁止Bot入口。

### 牌库与回合

- 2–5人沿用基础版：炸弹、拆弹、攻击、跳过、索要、洗牌、预知、否定及五种普通猫，共13种牌型。每人1拆弹+7张安全牌，危险牌数量按人数配置。
- 6人采用完整20张内爆猫扩展：内爆猫1、定向攻击3、反转4、抽牌底4、调整未来4、野猫4。默认总76张、每人8张、起始牌堆28张。
- 六人“加入内爆猫”“加入反转”独立开关，默认开；关闭内爆用第五张普通炸弹替代，关闭反转移除4张反转（总72张、起始牌堆24张）。2–5人不混入扩展。
- 合法同名两张随机取对手一牌，同名三张点名索取；功能牌可作为同名组合材料，野猫只按规则补普通猫组合。五张不同组合、快速变体不启用。
- 正常抽一张结束一个回合；攻击转移尚欠回合并叠加；跳过/反转只抵消一个回合；目标选择、预知、重排、索要、拆弹、秘密插回均由权威服务端验证。
- 抽普通炸弹后拆弹并秘密插回，无拆弹出局；内爆猫首次抽到翻面秘密插回，再次抽到翻面立即出局，不能拆弹或否定。最后存活者获胜。
- 对局冻结规则选项；旧快照保留原有房规，新建/再开按既定迁移行为执行。精确边界以[规则文档](02-规则与卡牌交互.md)、engine.js和行为测试为准。

### 计时与否定

| 设置 | 当前默认与行为 |
|---|---|
| 出牌不倒计时 | 默认关闭；开启后在线玩家行动、交牌、预知、重排、拆弹、插回不限时，否定仍独立配置 |
| 否定响应时长 | 10/20/30秒/不限时，默认10秒；API用0表示不限时；旧5/15秒只为兼容历史快照 |
| 可循环否定 | 默认开启；奇数次取消原动作、偶数次恢复；关闭时首张否定直接取消 |
| 响应资格 | 只对可否定的待生效动作开窗；只等待存活且持有否定的玩家；无人有资格直接流转 |
| 本次不出 | 本层提交后不可改成出牌，本人停止计时；全部有资格者完成可提前结算；新反否定层重新选择 |
| 离线处理 | 不限时否定的离线玩家单独10秒宽限后不出，其他离线选择托管；全体真人离线5分钟中止 |

## 3. 已批准并完成的UI、美术与交互

- 风格固定为Apple浅色基底＋原创可爱猫咪、奶油配景、圆润边框、细线和浅蓝胶囊按钮。用户已批准，不重复询问；新整体改版再确认。
- 停止Canva路线，静态美术使用GPT内置生图；交互与动画由实际Canvas代码实现。生成的宣传图不等于真实截图或已运行的动效。
- 首页图片优先，去冗余文字，设置移下方；昵称输入靠左垂直居中；首页、建房和主要选择框适配手机可用高度，一屏操作。
- 等待房每行两位玩家；对战模拟同一椭圆牌桌，所有头像留在桌内，头像/名字放大，行动头像用粗蓝圈，本人头像＋文字作为整体居中，游戏标题按屏幕居中。
- 手牌位置固定，默认折叠横滑，露出小牌名＋插画＋猫爪；选中/展开恢复详情，支持多选；末张之后不留可滑空白；展开与取消选择复用同款胶囊。
- 分类色：普通猫/野猫淡紫、拆弹淡绿、否定淡红、攻击/定向攻击淡橙黄、其余淡蓝；炸弹深红侧签、浅红底及鲜红牌名。牌背最后确认使用柔和粉红色白猫图，暖阳及蓝色版留作历史。
- 否定栏固定在打出/抽牌上方，布局不随页面滚动；等待本人时高亮，按钮居中，无资格或已响应置灰，闲置不显示“暂无响应”；细进度条显示剩余秒数。
- 公开出牌按队列每张展示5秒，角色姓名和牌名醒目；抽到炸弹展示抽牌者并播放丰富全屏爆炸，支持减少动态。新获得牌、拆弹与秘密放回提示角色明确、内容居中。
- 索要交牌只在手牌区域居中提示，不遮住牌桌；目标、预知、重排、插回等用独立居中弹框；目标卡展示大头像、姓名及剩余手牌数；私密预知提示合并窗口内。
- 退出/关房确认不被普通同步关闭；过期操作静默刷新，不弹“局面有变化”，不自动重放操作；缓存图集/头像减少闪烁。
- 六猫四狗头像可选，另提供本人主动授权的微信头像；拒绝授权仍能用动物头像。真实头像授权/下载及后台隐私配置还需专项真机验收。
- 右上角设置＋眼睛记录按钮；当前局公共历史和本人私密历史完整保留，隐私投影隔离。旧版已经截掉的事件无法补回；记录滚动但关闭按钮固定。

## 6. 常用操作与容易踩的坑

```sh
# 恢复当前云托管配置：默认检查不写入；--apply才应用并私有备份旧配置
npm run configure:cloudrun
npm run configure:cloudrun -- --apply
npm run check:release

# 本地浏览器/Bot验证：会把客户端配置切回本地，不能随后直接上传审核

npm test
npm run check
```

npm run dev:phone为同Wi-Fi开发；configure-preview是旧公网调试。完成本地调试后必须恢复cloudrun、重跑check:release并重新编译上传。首次下载仓库不会携带真实config.js，应主动配置。正式wechat模式Bot403是设计行为，不能为审核或方便试玩切换为local/preview。

仅后端修复无需重新上传已配置callContainer的体验包；前端配置或资源改变则必须重新编译上传并选为体验版。后台修改环境变量应进入实际新版本并重新部署；值只填原始文本，不带Markdown反引号。wx.cloud初始化环境和目标云托管环境不能混淆。
