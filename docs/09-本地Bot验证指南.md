# 本地 Bot 验证指南

v0.10.0，2026-10-03。一个人也能验证 2–6 人炸弹猫流程。Bot 使用本地规则策略，不调用大模型，也没有 API 费用。

当前微信工具已配置腾讯云公网调试，可直接重新编译扫码后添加 Bot；无需运行 Mac 本地后端。以下步骤用于本地浏览器或局域网模式，切换模式会重写客户端配置。见 [公网调试说明](10-公网测试与发布状态.md)。

## 开始一局

1. 项目根目录执行 `npm start`，保持终端运行。
2. 浏览器打开 <http://127.0.0.1:8787/>；或在微信开发者工具导入本项目并编译。
3. 填好昵称，点击“创建房间”。可开启“出牌不倒计时”，再点“创建好友房”；默认计时保持原规则。
4. 点击“添加验证 Bot”，选择 1–5 只；默认关闭“Bot 使用否定牌”，方便观察卡牌效果。
5. 点击“添加 Bot”。Bot 会标记为“Bot”并自动准备。
6. 点击“我准备好了”，再点“开始游戏”。

真人仍可以用房间号加入；所有席位合计最多 6 人。只有房主能在准备页添加或移除 Bot。准备页人数改变后，真人需重新准备，Bot 自动准备。

同 Wi-Fi 手机扫码验证时，使用 `npm run dev:phone` 代替 `npm start`，重新编译并生成真机调试二维码；手机上的 Bot 流程相同。

## 怎么验证

| 想检查什么 | 操作与预期 |
|---|---|
| 基础流程 | 点击抽牌结束回合；轮到 Bot 时，它约思考 1.5 秒后出牌或抽牌。抽牌后交给下家。 |
| 卡牌展示 | 左右滑动折叠手牌，点选查看名称和作用；可以多选，再点下方“打出”，居中弹窗选择目标并最终确认；不能单独打出普通猫。 |
| 索要与组合 | 选 Bot 作目标。索要时由 Bot 选择给你的牌；对子随机取牌；三张需声明牌种。有持否定响应者时等待确认或超时，无人能响应直接执行效果。 |
| Bot 向你索要 | 选择一张自己的手牌并交出；计时房超时按原规则托管，不限时房在线等待你选择。 |
| 攻击与跳过 | 观察“剩余回合”与当前行动者；攻击会转移余债再加二，跳过只完成一个回合。 |
| 预知 | 查看自己的私密前三张，按顺序显示；关闭后继续行动。对手看不到该结果。 |
| 拆弹与插回 | 抽到炸弹后使用拆弹，再选插回位置；没有拆弹会出局。Bot 会自动完成自己的特殊阶段。 |
| 否定链 | 另开一局，添加时开启“Bot 使用否定牌”；Bot 有否定牌时可取消真人效果，也会反否定自己的效果。建房开启“可循环否定”时奇数层取消、偶数层恢复；关闭时首张否定直接取消。 |
| 结算与再开 | 最后一名存活者获胜；房主点“再来一局”，Bot 保留并自动准备，真人再次准备后开局。 |
| 暂离与重连 | 进行中返回大厅会保留席位，可返回原局。所有真人离线时 Bot 暂停；不限时房离线后启动原阶段时长的托管，全员离线 5 分钟中止。 |
| 重启恢复 | 停止并重新 `npm start`，快照中的房间、Bot 与对局恢复；客户端重新进入后继续。过期阶段按原规则处理。 |

Bot 每个普通回合最多主动出一次牌（含同名组合），随后抽牌；特殊阶段会自动交牌、拆弹、插回和关闭预知。默认不使用否定，开关只影响添加的 Bot；需要不同设置时在准备页移除并重新添加。

出牌牌面约显示 5 秒，按顺序展示；组合显示牌名与张数。不限时模式下，你在线时出牌、交牌、预知确认、拆弹和插回都可慢慢验证，否定窗口按建房所选 10 / 20 / 30 秒或不限时，默认 10 秒。

## 范围与限制

Bot 只读取与真人相同的本人玩家视图，没有对手手牌或未知牌顶信息；插回位置随机选择。它是流程陪练，未设计难度等级或高强度策略，也不保证每局都会出现某张牌。遇到想验证的牌型，可多开几局。

入口仅在本地模式显示，后端同时校验登录身份、房主、准备阶段、人数、状态版本和回环来源，或同 Wi-Fi 的真实私网来源与有效调试访问码。正式微信模式禁用 Bot 接口和调度。手机不能直接使用 `127.0.0.1`；`dev:phone` 会生成电脑的局域网地址，同 Wi-Fi 可扫码调试。当前已具备腾讯云临时 HTTPS 公网调试；正式版仍需正式域名与真实微信身份。

对局数据保存在 `.data/state.json`，不会上传 GitHub。源码见 `server/bots.js`；自动检查使用 `npm test` 与 `npm run check`。

否定选择固定在页面底部的打出/抽牌操作栏上方，显示“是否选择否定”，不再自动弹窗。点击“本次不出”由服务器确认，本轮不可改为打出，本人停止计时并显示等待人数；全部持牌响应者确认或超时后结算，选完可提前结束。没有否定者自动完成，两个按钮置灰且不计入等待；持牌 Bot 同样确认。无人能响应时直接结算。开启循环时每张否定开启新响应层，其他仍持否定者可重新选择。更新后端后重新编译并生成真机调试二维码获取新包；公网模式无需同 Wi-Fi；dev:phone 模式仍需同 Wi-Fi。

六人默认加入完整内爆猫20张扩展；建房可分别关闭内爆猫与反转，数量变化见下节。Bot支持定向攻击、反转、抽牌底、私密重排、野猫组合与内爆首抽插回。一个房主添加五只Bot即可验六人版；添加1–4只Bot仍使用基础版。


## 六人自选扩展验证（v0.8.0）

创建房间时“加入内爆猫”和“加入反转”可独立切换，默认均开启。添加五只Bot开六人局才生效；少于六人仍基础版。建议分别验证四种组合：关闭内爆后5张普通炸弹且不会内爆翻面；关闭反转后没有反转牌或逆转动作；其他四种扩展仍可使用。再开保留房间设置，新建房重置为默认开启。
