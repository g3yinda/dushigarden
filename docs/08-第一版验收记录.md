## v0.1.1 本地 Bot 扩展验收

2026-09-30。首版基线已上传 GitHub `main` 并保存为 `v0.1.0` 标签；Bot 扩展使用 `v0.1.1`。

- 完整 `npm test`：72 项通过、0 失败、0 跳过；其中 Bot 11 项、规则 14 项、HTTP 7 项、房间 9 项、完整模拟 4 项、客户端 27 项。
- 原有 100 局规则模拟继续通过；新增 2–5 席各一局真实 BotRunner 完整推进，检查成功 Bot 指令计数、牌数守恒、隐私投影、胜者与再开自动准备。真人行动部分依赖超时托管，不等同于四局全程人工出牌。
- 新增回归覆盖同回合暂停重连后仍需抽牌、下一轮可以重新主动出牌，以及进行中预知阶段快照恢复后关闭并抽牌。Bot 回合记录与指令原子保存；公开回合编号区分新回合。
- 已修复两端离房竞态：提交离房前使旧轮询失效，原生端同时中止旧请求；失败恢复轮询。4 项 VM 行为测试覆盖时序、旧响应忽略与失败恢复。

实际 UI 检查：浏览器房间 671428 与微信模拟器房间 973422，均为一名真人加一只默认关闭否定的 Bot。两端完成添加、自动准备、真人准备与开局；日志可见 Bot 抽牌、跳过、索要、同名组合、预知和洗牌。对局经过正常倒计时托管走到 Bot 获胜结算，再开保留 Bot 并自动准备。最新后端重启后两端恢复结算页面。
