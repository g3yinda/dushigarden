# 精简首屏与固定操作栏 Implementation Plan

> 历史材料：本文件保留当时的设计、计划或验收，不作为当前行为说明。当前规则、UI、交付和待办见 [v0.9.5 当前状态](../../00-当前状态与文档索引.md)。

> **For agentic workers:** 在本会话按顺序执行与自检，不派生任务；用户已批准静态设计并授权更新公网测试与GitHub。

**Goal:** 默认折叠手牌时首屏显示完整出牌/抽牌按钮，删除桌面常驻冗余说明，保持现有卡牌权限与交互。

**Architecture:** 修改双端页面模板及样式，不改变权威引擎。固定底部操作栏预留安全区和内容空间；表格高度随窗口收紧，私密阶段允许内容滚动且操作条不会覆盖确认按钮。

**Tech Stack:** 原生小程序WXML/WXSS与HTML/CSS、现有共享控制器、Node24回归测试。
