# 炸毛猫咪：温暖牌桌改版

用户已批准本轮附图并要求直接实施。沿用 Apple 浅色及现有分类颜色，本次批准猫咪房间背景、奶油椭圆桌、较大头像/牌堆和图文猫爪折叠手牌。

## 范围

- 更新当前微信小游戏 Canvas 对战页；大厅、房间规则、服务端和旧浏览器/WXML参考保持各自基线。
- 独立房间背景由 GPT 内置生图生成，压缩为轻量 JPG；桌面、头像、牌数、牌名、按钮由真实代码绘制，不使用整页图片代替 UI。
- 牌桌、手牌、底栏固定分区，320×568 到 430×932 及不同微信胶囊/安全区均在一屏内。矮屏减少装饰和图文尺寸，保持操作目标至少44px；独立阶段弹框继续一屏操作。
- 椭圆桌面使用奶油色和细木色桌沿、少量猫爪，中央牌背、弃牌和回合信息；座位仍按本人视角真实顺序围坐，头像、姓名、牌数保持在桌框内。正常尺寸头像约56–72px，短屏约36px。
- 折叠牌露出横排小牌名、较大插画和分类色猫爪；每张至少44px宽触控。选中展开完整牌面，蓝框勾选；展开/收起、多选、横向拖动、取消和详情均保留，不能点牌立即打出。
- 猫/野猫紫、拆弹绿、否定红、攻击/定向攻击橙黄、其他蓝，普通炸弹深红标识/浅红底/鲜红牌名；不能以颜色替代名称。
- 否定行为、循环层、计时、退出确认、交牌手牌内提示、隐私弹框和爆炸队列不变。

## 验证

几何回归检查 2–6 人座位及中央牌堆无遮挡、手牌滑动与多选、固定底栏和各阶段位置、异形屏安全区。生产 Canvas 独立像素渲染截图逐尺寸目视复核；完整自动规则/HTTP/Bot测试和资源包检查。独立渲染不是微信真机截图，未上传和正式发布不得写为完成。
