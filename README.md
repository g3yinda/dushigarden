# 朋友小游戏 · BoomCat

都市花园的秘密基地 · 仓库：[g3yinda/dushigarden](https://github.com/g3yinda/dushigarden)。

首个游戏：炸弹猫。状态：**v0.7.1 稳定渲染与等待房间适配已实现**，包含微信原生小程序、权威后端和浏览器体验端。公网调试后端已部署腾讯云；微信正式线上版本尚未发布。

## 先运行

需要 Node.js 24，不需要安装第三方依赖。在本目录执行 `npm start`，打开 <http://127.0.0.1:8787/>。想一个人验证：创建房间 → 选择是否不限时和否定时长 → 添加验证 Bot（1–5 只）→ 我准备好了 → 开始游戏。Bot 自动准备并行动，不需要外部 AI 或付费服务。两个独立浏览器标签页也可以使用两个本地身份联机。

iPhone/Android 同 Wi-Fi 真机调试：先停止普通服务，执行 `npm run dev:phone`，再在微信开发者工具重新编译并生成真机调试二维码扫码。脚本自动配置电脑局域网地址，手机和模拟器分别选用正确入口，Bot 可用于单人调试。`miniprogram/config.js` 是本机生成配置，不进入 Git。

当前公网调试配置已生成；在微信开发工具重新编译 → 真机调试 → 微信扫码，即可跨网络连接云端。无需同 Wi-Fi。临时地址及正式发布状态见 [公网测试与发布状态](docs/10-公网测试与发布状态.md)。

微信开发者工具导入本目录，项目已配置 AppID `wx529cf19d338aebcf`。保持后端运行，再编译 `pages/home/home`。默认使用本地开发身份与回环地址；同 Wi-Fi 手机调试使用上面的 dev:phone 命令。

验证：`npm test`、`npm run check`。已通过 236 项测试，包含 2–6 人各 25 局完整自动对局。完整扩展的浏览器交互、公网六人开局与私密投影已验证；具体原生及真机验收范围见验收记录。

详见 [运行与部署说明](docs/07-第一版运行与部署.md)、[第一版验收记录](docs/08-第一版验收记录.md)、[本地 Bot 验证指南](docs/09-本地Bot验证指南.md)。

本版新增：房主退出时可仅自己离开，或二次确认后关闭整个房间，让所有成员回大厅并释放席位，不产生胜者。建房支持否定响应 15 / 10 / 5 秒，默认 10 秒，每次否定和反否定重新计时，再开沿用。手牌默认重叠收起，切换按钮为紧凑浅蓝胶囊，支持滑动和多选。不限时涵盖出牌、交牌、预知、拆弹和插回，否定仍按所选时长计时；离线仍托管。升级前已存在的房间保留原 5 秒，需新建房使用新设置。

否定选择固定在牌桌下方、手牌上方，显示“是否选择否定”，不再自动弹窗。点击“本次不出”由服务器确认，本轮不可改为打出，本人停止计时，原位置显示“已响应”及禁用按钮；全员确认或超时后结算，选完可提前结束。没有否定也可确认不出，Bot 同样确认，不泄露别人手牌。每张否定开启新的反否定响应层，其他玩家可以重新选择。

正常回合去除手牌教学、方向和桌面版本说明；手牌默认折叠，“打出 / 抽牌”并排固定在底部并避开安全区。不能操作时原位置灰，已选牌详情与无效原因按需显示。

公开行动逐张展示5秒，姓名加大加粗，蓝色牌名独立一行；否定栏常驻于牌桌和手牌之间，细进度条随剩余时间缩短并显示剩余秒数，非响应期按钮置灰。

六人新局包含内爆猫、定向攻击、反转、牌底抽牌、调整未来和野猫六种扩展牌，共76张，每人8张起手牌、牌堆28张。Bot 支持全部新牌与私密重排；旧六人对局保留原规则，结束再开才切换完整扩展。2–5 人保持基础版。

## 已确认

- 微信里的朋友聚会小游戏平台，后续会加入其他游戏。
- 现支持 **2–6 人**：2–5 人沿用基础规则；6 人采用用户于 2026-10-01 确认的完整内爆猫扩展（基础56张＋扩展20张）。
- **Apple 浅色 + 可爱猫咪**设计风格，用户于 2026-09-30 确认。
- 本项目今后**不使用 Canva**。页面效果图和卡牌美术使用 **GPT 内置生图**；真实交互和动画在后续开发实现。
- 先完成规则、需求和设计 Demo；用户随后明确批准按当前设计与需求开发第一版。
- 用户已提供 GitHub 仓库 `g3yinda/dushigarden`，用于首版代码和后续版本维护；私人环境与对局数据不进入仓库。
