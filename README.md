# 朋友小游戏 · BoomCat

都市花园的秘密基地 · 仓库：[g3yinda/dushigarden](https://github.com/g3yinda/dushigarden)。

首个游戏：炸弹猫。状态：**v0.10.1 固定牌桌与手牌**，包含原生 Canvas 小游戏、权威后端和浏览器体验端。公网调试后端已部署腾讯云；微信正式线上版本尚未发布。

## 先运行

需要 Node.js 24，不需要安装第三方依赖。在本目录执行 `npm start`，打开 <http://127.0.0.1:8787/>。想一个人验证：`npm test`、`npm run check`。小游戏新增运行桥、Canvas 操作与 2–6 人真实 HTTP 流程测试，具体数量和原生验收范围见 [当前状态](docs/00-当前状态与文档索引.md) 与 [验收记录](docs/08-第一版验收记录.md#v0100-微信小游戏适配)。旧 v0.9.5 的完整对局与服务器验收保留历史记录。

iPhone/Android 同 Wi-Fi 真机调试：先停止普通服务，执行 `npm run dev:phone`，再在微信开发者工具重新编译，iPhone点“预览”生成二维码扫码；Android/鸿蒙可点“真机调试”。脚本自动配置电脑局域网地址，手机和模拟器分别选用正确入口，Bot 可用于单人调试。`miniprogram/config.js` 是本机生成配置，不进入 Git。

当前公网调试配置已生成；在微信开发工具重新编译 → 预览（iPhone）或真机调试（Android/鸿蒙）→ 微信扫码，即可跨网络连接云端。无需同 Wi-Fi。临时地址及正式发布状态见 [公网测试与发布状态](docs/10-公网测试与发布状态.md)。

微信开发者工具导入本目录，项目已配置 AppID `wxf7af6d01a9bbfdbd`，后续开发上传与正式发布使用此新账号。保持后端运行，按“小游戏模式”普通编译，入口为 `miniprogram/game.js`。默认使用本地开发身份与回环地址；同 Wi-Fi 手机调试使用上面的 dev:phone 命令。

小游戏适配已完成：`compileType: game`，新增 `game.js` / `game.json`、Canvas2D 界面、原生键盘与触摸、前后台暂停/恢复和安全区适配。继续复用原有控制器、房间与权威规则；保留 WXML/WXSS 作为兼容基线。开发者工具已能显示首页、建房和好友房；正式发布仍需完成平台条件。

验证：`npm test`、`npm run check`。迁移前429项为当前483项回归的基线；原有125局加新增384局，共509局完整规则模拟，以及8局真实HTTP闭环全部结算；全量结果见 [当前状态](docs/00-当前状态与文档索引.md)。配置覆盖计时、循环否定和六人可选牌四组合。完整扩展的浏览器交互、公网六人开局与私密投影已验证；具体原生及真机验收范围见验收记录。

详见 [运行与部署说明](docs/07-第一版运行与部署.md)、[第一版验收记录](docs/08-第一版验收记录.md)、[本地 Bot 验证指南](docs/09-本地Bot验证指南.md)。

本版新增：房主退出时可仅自己离开，或二次确认后关闭整个房间，让所有成员回大厅并释放席位，不产生胜者。建房支持否定响应 10 / 20 / 30 秒或不限时，默认 10 秒，每次否定和反否定重新计时，再开沿用。手牌默认重叠收起，切换按钮为紧凑浅蓝胶囊，支持滑动和多选。不限时涵盖出牌、交牌、预知、拆弹和插回，否定单独按所选时长响应；离线仍托管。升级前已存在的房间保留其原时长和循环规则，需新建房使用新设置。

否定选择与出牌/抽牌一起固定在页面底部，位于行动按钮上方，显示“是否选择否定”，不再自动弹窗。点击“本次不出”由服务器确认，本轮不可改为打出，本人停止计时，原位置显示“已响应”及禁用按钮；全员确认或超时后结算，选完可提前结束。没有否定自动完成且按钮置灰，Bot 同样确认，不泄露别人手牌。“可循环否定”默认开启：每张否定开启新层，其他持否定玩家可重新选择，奇数取消原动作、偶数恢复。关闭时第一张否定立即取消原动作，不再反否定。

正常回合去除手牌教学、方向和桌面版本说明；手牌默认折叠，“打出 / 抽牌”并排固定在底部并避开安全区。不能操作时原位置灰，已选牌详情与无效原因按需显示。

公开行动逐张展示5秒，姓名加大加粗，蓝色牌名独立一行；否定栏常驻于固定底部出牌/抽牌操作栏上方，细进度条随剩余时间缩短并显示剩余秒数，非响应期按钮置灰。

六人新局默认包含内爆猫、定向攻击、反转、牌底抽牌、调整未来和野猫六种扩展牌，共76张，每人8张起手牌、牌堆28张。Bot 支持全部新牌与私密重排；旧六人对局保留原规则，结束再开才切换完整扩展。2–5 人保持基础版。

## 已确认

- 微信里的朋友聚会小游戏平台，后续会加入其他游戏。
- 现支持 **2–6 人**：2–5 人沿用基础规则；6 人采用用户于 2026-10-01 确认的完整内爆猫扩展（基础56张＋扩展20张）。
- **Apple 浅色 + 可爱猫咪**设计风格，用户于 2026-09-30 确认。
- 本项目今后**不使用 Canva**。页面效果图和卡牌美术使用 **GPT 内置生图**；真实交互和动画由小游戏 Canvas 与浏览器组件实现。
- 先完成规则、需求和设计 Demo；用户随后明确批准按当前设计与需求开发第一版。
- 用户已提供 GitHub 仓库 `g3yinda/dushigarden`，用于首版代码和后续版本维护；私人环境与对局数据不进入仓库。

小游戏缓存头像与牌面图集，按状态变动和动画刷新画面，减少重复加载；等待房间固定每行两位玩家。过期操作静默刷新最新局面，不弹“局面已变化”，也不自动重放旧命令；真实网络错误仍会提示。

本版否定只等待持牌玩家；无人能否定时立即结算。同一窗口内响应不会因其他人不出造成版本冲突，过期、换层和旧动作响应仍拒绝。否定按钮文字居中，优先使用系统圆体，闲置计时文字留空。

建房可分别关闭“内爆猫”和“反转”，仅六人扩展生效。无内爆时改用5张普通炸弹；无反转时移除4张反转，总牌数72、起始牌堆24张。其余扩展牌保留，2–5人仍基础版；设置在建房固定并沿用到再开。

退出及关闭房间的确认保留在最新牌局之上，只有主动取消、完成退出或房间失效才关闭；失去房主权限时关闭整个房间的确认失效。等待本人否定选择时，固定面板使用浅蓝背景与蓝边框，响应后恢复灰态。

建房弹框按手机可用高度一屏显示，所有规则和创建按钮不需上下滑动；采用简短副标题、至少44px触控目标和底部留白。浏览器与微信原生小屏分别检查，全部项目Markdown已复核，旧计划/设计与验收明确保留为历史。
