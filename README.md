# 朋友小游戏 · BoomCat

都市花园的秘密基地 · 仓库：[g3yinda/dushigarden](https://github.com/g3yinda/dushigarden)。

首个游戏：炸弹猫。状态：**v0.2.0 共同牌桌与折叠手牌版已实现**，包含微信原生小程序、权威后端和浏览器体验端。尚未部署公网后端或发布微信线上版本。

## 先运行

需要 Node.js 24，不需要安装第三方依赖。在本目录执行 `npm start`，打开 <http://127.0.0.1:8787/>。想一个人验证：创建房间 → 选择是否不限时 → 添加验证 Bot（1–4 只）→ 我准备好了 → 开始游戏。Bot 自动准备并行动，不需要外部 AI 或付费服务。两个独立浏览器标签页也可以使用两个本地身份联机。

微信开发者工具导入本目录，项目已配置 AppID `wx529cf19d338aebcf`。保持后端运行，再编译 `pages/home/home`。当前使用本地开发身份与回环地址，仅供本机模拟器验收。

验证：`npm test`、`npm run check`。已通过 103 项测试，包含 2–5 人各 25 局完整自动对局。微信模拟器与浏览器的建房、准备、开局、攻击/否定、离开/返回、结算/再开已实际联调。

详见 [运行与部署说明](docs/07-第一版运行与部署.md)、[第一版验收记录](docs/08-第一版验收记录.md)、[本地 Bot 验证指南](docs/09-本地Bot验证指南.md)。

本版新增：围坐共同牌桌、可滑动折叠手牌、多选后打出与居中头像目标弹窗、3 秒出牌展示队列，以及建房不限时开关。不限时涵盖出牌、交牌、预知、拆弹和插回，仅否定窗口保留 5 秒；离线仍托管。

- 微信里的朋友聚会小游戏平台，后续会加入其他游戏。

- 本项目今后**不使用 Canva**。页面效果图和卡牌美术使用 **GPT 内置生图**；真实交互和动画在后续开发实现。
