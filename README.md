## 当前小游戏体验链路

AppID：`wxf7af6d01a9bbfdbd`；自写原生Canvas2D小游戏，项目`compileType: game`，入口`miniprogram/game.js`。当前体验路线为真实微信登录＋wx.cloud.callContainer，目标云托管`prod-d2gqiy08z19bd1427/boomcat`，云初始化环境`cloudbase-d7gs58am20088d298`；两个环境用途不同。旧腾讯云临时隧道只作独立历史preview验证。

首次下载仓库不会获得被忽略的真实客户端config.js。使用Node.js24，恢复已确认云托管公开配置：

```sh
npm run configure:cloudrun -- --apply
npm run check:release
```

再在微信开发者工具导入本目录，以小游戏模式编译。AppSecret仅在后端运行环境私下设置，不写前端。仅后端变更不需要重传已切换callContainer的体验包；前端配置/代码改变需要重新编译上传。

## 已实现功能及历史迭代索引

以下内容保留功能与版本演进；具体日期的“当前/未完成”只表示当时，最新结果以上文及交接文档为准。

本版新增：房主退出时可仅自己离开，或二次确认后关闭整个房间，让所有成员回大厅并释放席位，不产生胜者。建房支持否定响应 10 / 20 / 30 秒或不限时，默认 10 秒，每次否定和反否定重新计时，再开沿用。手牌默认重叠收起，切换按钮为紧凑浅蓝胶囊，支持滑动和多选。不限时涵盖出牌、交牌、预知、拆弹和插回，否定单独按所选时长响应；离线仍托管。升级前已存在的房间保留其原时长和循环规则，需新建房使用新设置。

否定选择与出牌/抽牌一起固定在页面底部，位于行动按钮上方，显示“是否选择否定”，不再自动弹窗。点击“本次不出”由服务器确认，本轮不可改为打出，本人停止计时，原位置显示“已响应”及禁用按钮；全员确认或超时后结算，选完可提前结束。没有否定自动完成且按钮置灰，Bot 同样确认，不泄露别人手牌。“可循环否定”默认开启：每张否定开启新层，其他持否定玩家可重新选择，奇数取消原动作、偶数恢复。关闭时第一张否定立即取消原动作，不再反否定。

选人弹框放大头像和姓名，减少卡片内部留白，显示每位玩家公开的“剩余 X 张牌”；实时同步且保持确认按钮一屏可见。

小游戏中被索要牌时，仅高亮手牌并显示索要者及交牌提示，底部主按钮切换“交牌”；牌桌和手牌位置保持固定。预知、调整未来、拆弹、插回、出牌选人和三张组合点名均使用独立居中弹框，不纵向滚动；插回位置采用加减和牌顶/随机/牌底快捷选择，点名在同一弹框内分页。此变更适用于当前Canvas小游戏，旧WXML/浏览器保留基线。

正常回合去除手牌教学、方向和桌面版本说明；手牌默认折叠，“打出 / 抽牌”并排固定在底部并避开安全区。不能操作时原位置灰，已选牌详情与无效原因按需显示。

公开行动逐张展示5秒，姓名加大加粗，蓝色牌名独立一行；否定栏常驻于固定底部出牌/抽牌操作栏上方，细进度条随剩余时间缩短并显示剩余秒数，非响应期按钮置灰。

六人新局默认包含内爆猫、定向攻击、反转、牌底抽牌、调整未来和野猫六种扩展牌，共76张，每人8张起手牌、牌堆28张。Bot 支持全部新牌与私密重排；旧六人对局保留原规则，结束再开才切换完整扩展。2–5 人保持基础版。

本版否定只等待持牌玩家；无人能否定时立即结算。同一窗口内响应不会因其他人不出造成版本冲突，过期、换层和旧动作响应仍拒绝。否定按钮文字居中，优先使用系统圆体，闲置计时文字留空。

退出及关闭房间的确认保留在最新牌局之上，只有主动取消、完成退出或房间失效才关闭；失去房主权限时关闭整个房间的确认失效。等待本人否定选择时，固定面板使用浅蓝背景与蓝边框，响应后恢复灰态。
