# 朋友小游戏 · BoomCat

都市花园的秘密基地 · 仓库：[g3yinda/dushigarden](https://github.com/g3yinda/dushigarden)。

首个游戏：炸弹猫。状态：**v0.3.2 页面内否定响应版已实现**，包含微信原生小程序、权威后端和浏览器体验端。尚未部署公网后端或发布微信线上版本。

## 先运行

需要 Node.js 24，不需要安装第三方依赖。在本目录执行 `npm start`，打开 <http://127.0.0.1:8787/>。想一个人验证：创建房间 → 选择是否不限时和否定时长 → 添加验证 Bot（1–4 只）→ 我准备好了 → 开始游戏。Bot 自动准备并行动，不需要外部 AI 或付费服务。两个独立浏览器标签页也可以使用两个本地身份联机。

iPhone/Android 同 Wi-Fi 真机调试：先停止普通服务，执行 `npm run dev:phone`，再在微信开发者工具重新编译并生成真机调试二维码扫码。脚本自动配置电脑局域网地址，手机和模拟器分别选用正确入口，Bot 可用于单人调试。`miniprogram/config.js` 是本机生成配置，不进入 Git。

微信开发者工具导入本目录，项目已配置 AppID `wx529cf19d338aebcf`。保持后端运行，再编译 `pages/home/home`。默认使用本地开发身份与回环地址；同 Wi-Fi 手机调试使用上面的 dev:phone 命令。

验证：`npm test`、`npm run check`。已通过 144 项测试，包含 2–5 人各 25 局完整自动对局。微信模拟器与浏览器的建房、准备、开局、攻击/否定、离开/返回、结算/再开已实际联调。

详见 [运行与部署说明](docs/07-第一版运行与部署.md)、[第一版验收记录](docs/08-第一版验收记录.md)、[本地 Bot 验证指南](docs/09-本地Bot验证指南.md)。

本版新增：房主退出时可仅自己离开，或二次确认后关闭整个房间，让所有成员回大厅并释放席位，不产生胜者。建房支持否定响应 15 / 10 / 5 秒，默认 10 秒，每次否定和反否定重新计时，再开沿用。手牌默认重叠收起，切换按钮为紧凑浅蓝胶囊，支持滑动和多选。不限时涵盖出牌、交牌、预知、拆弹和插回，否定仍按所选时长计时；离线仍托管。升级前已存在的房间保留原 5 秒，需新建房使用新设置。

否定选择固定在牌桌下方、手牌上方，显示“是否选择否定”，不再自动弹窗。点击“本次不出”由服务器确认，本轮不可改为打出，本人停止计时并显示等待人数；全员确认或超时后结算，选完可提前结束。没有否定也可确认不出，Bot 同样确认，不泄露别人手牌。每张否定开启新的反否定响应层，其他玩家可以重新选择。
